## 🌌 About

This is not just a script. It's a **ritual**.

`metamorphosis-404` is an interactive terminal experience — a poetic simulation of a developer undergoing metamorphosis into a **404 Not Found page**. It explores what happens when constant availability becomes unbearable, and how the act of disappearing can become the most liberating deployment you'll ever make.

The project lives at the intersection of **code and poetry**, **burnout and beauty**, **presence and deliberate absence**.

---

## 📖 The Full Poem

The complete poetic essay is in [`POETIC.md`](./POETIC.md). It's a reflective, vulnerable meditation on modern developer life — told through wordplay, HTTP metaphors, and the quiet longing to be un-indexed.

A tiny taste:

> *"Not Found. Not Bound. Not drowned in the sound of the crowd."*  
> *"return null; // returning to myself, at last."*

## 🚀 Quick Start

### Prerequisites
- Python 3.8 or higher
- Nothing else. No `pip install`. No virtual environment. Just you and the terminal.

### Run the ritual

```bash
git clone https://github.com/ggle_in/metamorphosis-404.git
cd metamorphosis-404
python3 metamorphosis_404.py
```

Then let it play out. To exit after the loop starts, press `Ctrl+C` — the script will exit gracefully with a gentle farewell message.

## 🎬 What You'll Witness

#### Act I — The Requests
A developer answers endless GET requests (revenue, status, deadlines) with a trembling 200 OK.

#### Act II — The Panic
Kernel panic. The spirit segfaults. "Too many file descriptors. Too many open mouths."

#### Act III — The Shedding
A transformation. The developer methodically uninstalls expectations, ambitions, and identities until becoming a simple, serene 404 page.

#### Act IV — The Quiet
The 404 page loops forever — occasionally serving poetic refusal messages to mistaken visitors, but mostly resting in silence. All centered on a clean screen.
