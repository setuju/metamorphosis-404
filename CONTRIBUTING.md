# Contributing to the Quiet

Thank you for finding this page. Even a 404 welcomes visitors.

This is not a typical repository. It is a **resting place** — a deliberate absence in a web of noise. If you’d like to contribute, you are invited to do so gently, thoughtfully, and with the same spirit of stillness that birthed this project.

## Ways to Contribute

### 🖋 Add a Stanza
Poetry is not finished; it only pauses. If you have a verse — a new metaphor, a continuation of the metamorphosis — open a pull request. Place your `.md` file in the `verses/` directory. Let your words be a quiet echo of the original.

### 🐛 Report a Glitch
Did the script crash before reaching silence? Did a line of code break the spell? Open an issue. Describe what you saw, what you expected, and what the silence should have felt like. We’ll debug it like we debug the soul: patiently.

### 🎨 Offer Visual Stillness
ASCII art, terminal color schemes, or even a haiku that fits the mood — all are welcome. If you can make the terminal breathe with even less effort, we want to see it.

### 🌍 Translate the Silence
Help bring this poem to other languages. Create `POETIC_<lang>.md`. Keep the metaphors intact, but let them whisper in your native tongue.

## Guidelines for Pull Requests

- **Keep the tone reflective and human.** Perfect grammar is optional. Honesty is not.
- **If you’re adding code, ensure it runs on Python 3.8+ with zero external dependencies.** This page needs no libraries. It only needs to be.
- **For major changes, open an issue first.** Let's discuss before disturbing the silence.
- **Leave a trace.** If you remix this work, link back to the original 404. A comment, a nod — it’s enough.

## Code of Conduct

Be gentle. This is a quiet space.

- Don’t shout in issues.
- Don’t demand features.
- Remember that every contributor is a human being, possibly on the edge of burnout, possibly in the middle of their own metamorphosis.

## A Final Note

This repository exists because someone once whispered:

> *"Maybe I should just be a 404 page."*

If you’ve ever felt that way, you belong here. Whether you contribute a line of code or simply sit in silence and read, you are part of this strange, gentle, un-indexable corner of the web.
